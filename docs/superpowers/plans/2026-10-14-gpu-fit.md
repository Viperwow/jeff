# Several Local Models on One GPU Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Before a local model installs, show whether it fits in GPU memory beside the models already running, let fitting models run together, and offer "Stop current and install" when it does not fit.

**Architecture:** `src/install.rs` reads the GPU through `nvidia-smi`, computes the fit from each stack's declared requirement, and writes each stack's own `--gpu-memory-utilization` share into the compose file it renders. `src/main.rs` serves the fit at `GET /api/{stack}/fit`, accepts `{"stop_others": true}` on install, and gives `jeff install` a `--stop-others` flag. `ui/app.js` replaces Install/Uninstall with the confirmation and draws the bar.

**Tech Stack:** Rust (axum, serde_json, clap), vanilla JS, Tailwind CSS 4 (`ui/app.css` built to `ui/dist/app.css` with `pnpm -s build` in `ui/`).

**Spec:** `docs/superpowers/specs/2026-10-14-gpu-fit-design.md`

## Global Constraints

- GPU numbers come from `nvidia-smi --query-gpu=memory.total,memory.used --format=csv,noheader,nounits`, first line only (GPU index 0). Values are MiB; jeff shows GiB (MiB ÷ 1024), one decimal, except `Your GPU N GB`, which rounds to a whole number.
- Other programs = memory in use − the sum of the running jeff stacks' requirements, floored at 0.
- A stack starts with share = required GB ÷ GPU GB, rounded up to two decimals. When jeff cannot read the GPU, the compose file keeps `0.85`.
- The stack being installed is never counted as running.
- UI copy, exact: `Install`, `Stop current and install`, `Install anyway`, `Cancel`, `Required GPU memory X GB`, `Your GPU N GB`, `Your GPU: unknown`, `Other apps X GB, live`, `<Model> X GB`, `<Model> requires X GB: Y GB fits, Z GB does not fit`, `<Model> requires X GB, all fits`, `Free X GB`, `Could not read your GPU memory, so it cannot tell whether this fits.`
- Bar: 5 px tall; new model hatched; green up to the GPU mark, red after it, red reaching the right edge; scale = GPU size when it fits, else ceil(required × 1.08) fixed when the confirmation opens; refresh every 2 s.
- No new dependencies. Follow the commit style `feat: …` / `fix: …`, no AI attribution.

## Review Focus

- `nvidia-smi` prints several GPUs, trailing spaces or a blank line: jeff reads the first GPU and ignores the rest.
- A stack installed before this change still runs at 0.85 and uses more than its requirement: other programs must floor at 0, never show a negative number.
- Reinstalling the model that runs: it must not count twice, so a model that fits alone keeps showing `Install`.
- `--stop-others` when removing another stack fails: the install must not start, and the error must name the stack that failed to stop.
- `nvidia-smi` stops answering while the confirmation is open: the page switches to the unknown variant instead of throwing.

### Task 2: Fit arithmetic and the compose share

**Files:**
- Modify: `src/install.rs`

**Interfaces:**
- Consumes: `Gpu`, `Stack::required_gb` (Task 1).
- Produces:
  - `pub struct Fit { pub gpu: Option<Gpu>, pub running: Vec<(Stack, f64)>, pub other_gb: f64, pub required_gb: f64, pub new_gb: f64 }` where `required_gb` = other + running + new.
  - `impl Fit { pub fn fits(&self) -> Option<bool>; pub fn short_gb(&self) -> f64; pub fn to_json(&self, stack: Stack) -> serde_json::Value }`.
  - `fn fit_from(stack: Stack, gpu: Option<Gpu>, running: &[Stack]) -> Fit` (pure) and `pub fn fit(stack: Stack) -> Fit` (calls `gpu()` and `Stack::running()` for every other stack).
  - `fn render_compose(stack: Stack, gpu: Option<Gpu>) -> String`.
  - JSON shape: `{"gpu": {"total_gb", "used_gb"} | null, "running": [{"id", "name", "gb"}], "other_gb", "new": {"id", "name", "gb"}, "required_gb", "fits": bool | null, "short_gb"}`.

- [ ] **Step 1: Write failing tests:**

```rust
#[test]
fn fit_counts_others_and_floors_other_apps() {
    let gpu = Some(Gpu { total_gb: 16.0, used_gb: 11.6 });
    let f = fit_from(Stack::Clm, gpu, &[Stack::H2oLightning]);
    assert_eq!(f.running, vec![(Stack::H2oLightning, Stack::H2oLightning.required_gb())]);
    assert!((f.other_gb - (11.6 - Stack::H2oLightning.required_gb()).max(0.0)).abs() < 1e-9);
    let started_at_085 = fit_from(Stack::Clm, Some(Gpu { total_gb: 16.0, used_gb: 13.9 }), &[Stack::H2oLightning]);
    assert!(started_at_085.other_gb >= 0.0);
}

#[test]
fn fit_leaves_out_the_stack_being_installed() {
    let f = fit_from(Stack::H2oLightning, Some(Gpu { total_gb: 16.0, used_gb: 11.6 }), &[Stack::H2oLightning]);
    assert!(f.running.is_empty());
}

#[test]
fn fit_is_unknown_without_a_gpu() {
    let f = fit_from(Stack::Clm, None, &[]);
    assert_eq!(f.fits(), None);
    assert_eq!(f.other_gb, 0.0);
}

#[test]
fn compose_gets_the_stack_share() {

    assert!(c.contains(&format!("--gpu-memory-utilization {share}")));
    assert!(render_compose(Stack::Clm, None).contains("--gpu-memory-utilization 0.85"));
}
```
